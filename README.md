# SteeringLab

直線ステアリング課題の A（移動距離）、W（通路幅）、ID、角度を設定し、画面の対角インチと解像度から表示実寸を確認できる実験用ツールです。

## 主な機能

- A / W の自由入力と `ID = A / W` の自動計算
- 上部タブで設定を切り替える全画面レイアウトと常時プレビュー
- 元の C1〜C4 条件のプリセット
- 直線角度の変更とライブプレビュー
- 対角インチ・画面サイズ（CSS px）による mm 換算
- 定規で測った基準線による実寸校正と、表示環境の変化に応じた再校正の案内
- START / バッファ / A区間 / バッファ / END の課題構造（前後バッファの初期値は各200px、個別変更可能）
- 実寸（1 CSS px = 1設定px）での全画面試行と、カーソルオーバーで開く設定パネル
- コア区間MT、通路逸脱回数・時間・最大逸脱量の計測
- 全画面解除、試行終了、設定JSON出力
- 端末内への設定自動保存

## 実寸の校正

設定パネルの「画面」→「基準線を測って校正」を開き、左右の縦線の中心間を定規で測ってmm単位で入力し、「校正を保存」を押します。基準線は広い画面では600 CSS px、狭い画面では表示領域に合わせた長さになり、実際の描画幅から換算係数を求めます。校正してもA・WのCSS px指定や試行の描画・計測条件は変わりません。

校正値は端末内に保存し、JSONにも含めます。校正済みのmm表示は測定値に基づきますが、精度は定規の読み取り精度に依存します。画面サイズ・ピクセル比・ピンチズーム倍率の変化を検出すると校正値の適用を止め、「要再校正」と表示して画面設定からの推定値を使います。同じ解像度・倍率の別モニターへの移動は検出できない場合があるため、モニター変更時は再校正してください。校正中に基準線の長さ・表示倍率が変わった場合は入力をクリアし、測り直しを案内します。

「校正を解除」で従来の推定換算に戻せます。HTML版・React版の両方で利用できます。

## 起動

### いちばん簡単な方法

`steering_task_configurator.html` をブラウザで開くだけで利用できます。インストールやサーバー起動は不要です。

### 開発版

```bash
npm install
npm run dev
```

本番ビルドは `npm run build`、テストは `npm test` で実行します。
